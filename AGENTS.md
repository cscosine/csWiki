# AGENTS.md

Entry point for coding agents (and people) working in csWiki: the wiki of cscosine

The rules of every cscosine repository are in [.claude/cscosine-rules.md](.claude/cscosine-rules.md) (owned by the
project template): read them first. This file holds what is specific to this repository.

## Commands

- Setup: `./setup.sh` (Windows: `.\setup.ps1`), then `source .venv/bin/activate`.
- Checks: `pre-commit run --all-files`; tests: `pytest`.
